# 하루노트

매일의 **아이디어 💡**, **메모 📝**, **일기 📔**를 기록하는 웹 앱입니다.
서버 없이 동작하며, 모든 기록은 브라우저의 `localStorage`(이 기기)에만 저장됩니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 빌드나 설치가 필요 없습니다.

```bash
# 또는 로컬 서버로 실행
python3 -m http.server 8000   # http://localhost:8000
```

## 스마트폰에서 사용하기

1. GitHub 저장소 **Settings → Pages**에서 Source를 *Deploy from a branch*, 브랜치 `ccr-427e4c82-jlbtqe` / `/ (root)`로 저장
2. 1~2분 뒤 `https://redflash7.github.io/ai-chatbot/` 접속
3. 홈 화면에 추가
   - iPhone(Safari): 공유 버튼 → **홈 화면에 추가**
   - Android(Chrome): ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

홈 화면 아이콘으로 열면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 오프라인에서도 동작합니다.
기록은 그 휴대폰 안에만 저장되며 PC와 자동 동기화되지 않습니다(백업 파일로 옮길 수 있음).

## 기능

- 달력으로 날짜를 선택해 그날의 기록 작성·조회 (기록이 있는 날은 종류별 색 점 표시)
- 기록 종류: 아이디어 / 메모 / 일기 (일기는 기분 선택 가능)
- 제목·태그(쉼표 구분), 상단 고정(★), 수정(날짜 이동 포함), 삭제
- 전체 검색: 제목·내용·태그 검색, `#태그`로 태그 정확히 검색, 결과 하이라이트
- 종류별 필터와 통계
- `Ctrl/⌘ + Enter`로 빠르게 저장
- JSON 백업 내보내기/불러오기 (같은 기록은 더 최근에 수정된 쪽으로 병합)
- 다크 모드, 모바일 화면 지원, 여러 탭 간 자동 동기화
- PWA: 홈 화면 설치, 오프라인 실행

## 데이터 저장

- 저장 키: `localStorage["harunote:v1"]`
- 브라우저 데이터를 지우거나 다른 브라우저/기기에서는 기록이 보이지 않으니, 주기적으로 **백업 내보내기**를 권장합니다.
